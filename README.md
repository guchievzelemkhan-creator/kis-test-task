Чтобы запустить решение нужно выполнить последовательно
pip install -r requirements.txt
python main.py


Проектные решения.
1) Проект разделен на три части:
    main.py - вся серверная логика
    data/ - папка для хранения всех таблиц и их связей в моей базе данных
    templates/ - весь фронтэнд
2) Использовал удобную ORM sqlalchemy для работы с пользовательскими данными. Для каждого запроса открывается новая сессия и закрывается как в случае работы без ошибко, так и в случае наличия ошибки. Для методов которые меняют данные использованы try/except с использованием rollback для случая когда выпало исключение. 
3) Реализовано два способа представления обещаний: через карточки и через диаграмму Ганта. Также реализовано фильтрование записей по гильдиям, датам и статусам. Также реализован поиск.
4) Использован selectinload, чтобы справиться с ошибкой DetachedInstanceError.
